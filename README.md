# Latent-Space Observatory — personal research site

The personal / academic website of **S. Mohammad H. Hosseini D.** — a dark,
navy-dominant, mathematically-themed research portfolio built around generative
models, stochastic processes, density estimation, topology, and the
mathematical foundations of deep learning.

Live: <https://mhohosseini.github.io/>

> **Design intent** — a *mathematical latent-space observatory*: a deep-navy
> cosmic canvas of animated constellations, a flow-field drift inspired by
> stochastic differential equations, and a slow "diffusion" breathing where
> particles condense into structure and disperse again. Elegant, serious,
> readable — never noisy sci-fi.

## 1. Why this stack (design & engineering rationale)

The site began as the [al-folio](https://github.com/alshedivat/al-folio) Jekyll
theme. It was rebuilt from scratch into a **bespoke, dependency-free static
site** generated by a single Python script.

**Why not keep al-folio or migrate to Astro/Three.js?**

- al-folio is instantly recognizable as a template and its bibliography/CV data
  were still full of the theme's Einstein placeholders. The brief was to *not*
  look like a template.
- A heavy JS stack (Astro + React + Three.js) would add a large dependency tree
  for what is, in the end, a content site — working against the explicit goals
  of *max performance*, *no console errors*, and *no dependency mess*.
- The visual centrepiece — the constellation / flow-field / diffusion
  background — is a hand-written **2D `<canvas>` engine** (`src/js/cosmos.js`).
  It is lighter and far more mobile-friendly than WebGL, needs no libraries,
  and respects `prefers-reduced-motion`.

The result: **zero runtime dependencies**, **zero third-party build tools**
(Python standard library only), a Lighthouse-friendly footprint, and total
creative control. MathJax is the only external asset, lazy-loaded from a CDN
only on project pages that contain equations.

**Design system**

- **Palette** — deep navy near-black background; cyan, electric blue, violet,
  and muted gold accents. Tokens live at the top of `src/css/site.css`.
- **Type** — `Fraunces` (display serif) · `Inter` (body) · `JetBrains Mono`
  (technical accents), via Google Fonts.
- **Motion** — scroll-reveals, orbital portrait rings, card pointer-glow, and
  the canvas engine. Everything collapses to a static, calm state under
  `prefers-reduced-motion`.

```
│   └── js/
│       ├── cosmos.js     # ← the animated constellation background
│       ├── dynamics.js   # ← the interactive ODE/SDE landing panel
│       └── app.js        #   nav, filters, scroll reveals

```

Pages generated: `/`, `/research/`, `/projects/`, `/projects/<slug>/` (one per
project), `/publications/`, `/teaching/`, `/blog/`, `/blog/<slug>/` (one per
post), `/cv/`, plus `404.html`, `sitemap.xml`, `robots.txt`, `favicon.svg`, and
`.nojekyll`.

The homepage opens with a **full-screen ODE/SDE "trailer"** (`src/js/dynamics.js`)
above everything else: pick one of ten dynamical systems and watch an ensemble
propagate over its live vector-field geometry (streaks, fixed points, reference
grid), then scroll down to the name + portrait and the rest of the site. The site
mark is a minimal two-arm **cyclone** (spiral) defined in `build.py` (`GLYPH` for
the nav, `FAVICON` for the tab icon).

## 3. Run locally

Requires **Python 3.9+** only. No `pip install`, no Node, no Ruby.

```bash
python build.py                       # generates ./dist
python -m http.server -d dist 8000    # serve it
# open http://localhost:8000
```

Re-run `python build.py` after any content or style change, then refresh.

## 4. Editing content

All content is plain JSON in `data/`. After editing, run `python build.py`.

Text fields in **project bodies** support light Markdown — `*italic*`,
`**bold**`, `` `code` ``, `[links](url)` — and LaTeX math with `$inline$`.
Display equations use the `equation` field (no `$…$` needed).

### Add a project

Append an object to `data.projects` in `data/projects.json`:

```json
{
  "id": "my-new-project",
  "title": "My New Project",
  "tagline": "A one-line thesis.",
  "category": "Generative Models",
  "importance": 5,
  "featured": true,
  "status": "Study & implementation",
  "year": "2025",
  "image": "my_diagram.png",
  "tags": ["Tag A", "Tag B"],
  "links": { "code": "", "paper": "", "report": "",
             "reference": "https://arxiv.org/abs/...", "reference_label": "Author (Year)" },
  "sections": [
    { "heading": "Motivation", "body": ["First paragraph…", "Second paragraph…"] },
    { "heading": "Method",
      "body": ["We use the change-of-variables formula."],
      "equation": "\\log p_X(x) = \\log p_Z(f(x)) + \\log\\left|\\det J\\right|" }
  ]
}
```

- `id` → the URL `/projects/<id>/`.
- `category` must match an entry in the top-level `categories` array (that array
  also controls the filter buttons and their order).
- `featured: true` also shows the project on the homepage.
- Put the diagram image in `assets/img/` first.

### Add a publication

Append to `data.publications` in `data/publications.json` (newest first):

```json
{
  "id": "unique-key", "title": "…", "year": 2025,
  "authors": [ { "name": "S. M. Hosseini D.", "me": true }, { "name": "Co-Author" } ],
  "venue": "NeurIPS 2025", "status": "Accepted",
  "selected": true,
  "tags": ["Diffusion"], "abstract": "…",
  "links": { "pdf": "", "arxiv": "", "code": "", "blog": "" }
}
```

`"me": true` highlights your name in cyan; `selected: true` stars it and shows
it on the homepage.

### Add a blog post

Create a Markdown file in `data/blog/` — the filename becomes the URL slug
(`data/blog/my-post.md` → `/blog/my-post/`). Start it with a frontmatter block:

```markdown
---
title: My post title
date: 2026-07-05
tags: optimal transport, geometry
description: One-line summary shown on the blog index and social cards.
math: true
---

Write in **Markdown**: headings (`##`), lists, `> quotes`, `code`, links, images.
Inline math with $a^2 + b^2 = c^2$ and display math on its own line:

$$ \int_0^1 f(x)\,dx $$
```

Set `math: true` (or just include a `$`) to load MathJax on that post. The two
most recent posts also appear in the homepage "Writing" section. Run
`python build.py` and the post, its page, and the sitemap update automatically.

### Other content

- **Teaching** → `data/teaching.json` (image in `assets/img/`).
- **News** → `data/news.json` (`html` allows inline tags like `<em>`).
- **Bio / homepage** → `data/about.json`.
- **Research cards** → `data/research.json` (`motif` ∈ diffusion, flow, manifold,
  topology, graph, constellation; `accent` ∈ cyan, violet, gold).
- **CV** → `data/cv.json`. Items with `"todo": true` render as dashed
  “to add” placeholders — fill them in and drop the flag. Replace the PDF at
  `assets/pdf/Curriculum_Vitae.pdf`.
- **Socials / meta** → `data/site.json`. Leave a social value `""` to hide it.

## 5. Customize the look

- **Colors & spacing** — the `:root` tokens at the top of `src/css/site.css`
  (`--bg`, `--cyan`, `--violet`, `--gold`, `--panel`, radii, max-widths…).
- **Fonts** — swap the Google Fonts `<link>` in `build.py` (`head()`), then the
  `--font-*` tokens.
- **Background animation** — `src/js/cosmos.js`. Tunable constants near the top:
  `nodeCount()` (density), `COLORS`, flow strength, `linkDist`, cursor radius.
- **Landing ODE/SDE panel** — `src/js/dynamics.js`. The `SYSTEMS` array defines
  each system: its `name`, `kind` (`"ODE"`/`"SDE"`), display `eq`, `note`, the
  vector field `f(x, y)`, and the noise level `sigma`. Add or remove a system by
  editing that array — the selector buttons build themselves.
- **Logo / favicon** — the cyclone mark lives in `build.py` (`GLYPH`, `FAVICON`,
  and the `_CYC0`/`_CYC1` spiral paths).

Both animations fall back to a single static frame under `prefers-reduced-motion`.

## 6. Deploy (GitHub Pages)

Deployment is automated by `.github/workflows/deploy.yml`: on every push to
`main` it runs `python build.py` and publishes `dist/` to the **`gh-pages`**
branch.

**One-time setup:** repo **Settings → Pages → Build and deployment → Source →
“Deploy from a branch” → branch `gh-pages` / `root`**. (This is the default for
most `<user>.github.io` repos, so it may already be set.)

Prefer GitHub's native Actions deployment? The workflow file contains a
ready-to-use alternative job — see its trailing comment.

Custom domain: add a `CNAME` file (build.py writes `.nojekyll` so Pages won't
re-run Jekyll on the output).
